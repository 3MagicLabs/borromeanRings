# textkit

A tiny text-utility library (`slugify`, `word_count`, `truncate`) — **an example
project governed by [borromeanRings](../../README.md)**, a different archetype
than the meta-harness itself.

It has its own `borromeanrings.toml` declaring a library-appropriate gate. Run it
from the repo root:

```bash
BORROMEANRINGS_PROJECT=examples/textkit bash verify.sh
```

borromeanRings's code lives at the repo root; `textkit` is governed *by* it —
demonstrating the portability claim ("enforces best practices for any project").
